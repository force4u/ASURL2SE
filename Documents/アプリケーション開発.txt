macOS 27 用の小さなアプリを、Swift(AppKit)で作ってほしい。
私は Xcode のビギナーで、Swift は書けない。
まずは「可能か?」の判断だけ。ソースは、まだいらない。

【背景】
macOS 27 の Script Editor が、applescript: スキームを受け取らなくなった。
Chromium 系のブラウザも、このURLを外に渡さない(確認済み)。Safari は渡す。
ClickFix 対策としての変更には賛成。なので、実行はせず、
「内容を見て、自分で判断する」ための、自分専用アプリにしたい。

【やりたいこと】
1. applescript: URL を受信(Safari のクリック、.inetloc のダブルクリック経由)
   → デコードして、Script Editor の新規書類に、テキストとして入れる。実行も保存もしない。
2. アプリを起動したとき、クリップボードが applescript: URL か、普通のテキストなら、同じ処理。
   空、または Option キーを押して起動したら、設定画面。起動済みで Dock をクリックしても、同じ。
3. 設定画面: URLの送信先アプリの変更(setDefaultApplication)、確認ダイアログの有無。
4. 処理が終わって60秒後に自動終了。設定画面が開いている間は止める。
   Dock に表示する(固まったときに強制終了できるように)。メニューは、終了とアバウトだけ。

【環境・制約】
Apple Silicon のみ。macOS 27 以上。Xcode のバージョン: ○○(Swift 6 モード)。
署名は Sign to Run Locally(ストーリーボードなし、メインウィンドウなし)。
あなたはビルドできないので、コンパイルエラーは、私が貼る。
